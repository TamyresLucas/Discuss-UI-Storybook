New overlay token `overlay-destructive-20` (`--sys-color-overlay-destructive-20`, Tailwind `from-overlay-destructive-20`): the coral of the destructive text at 20% opacity. Use it only for the hover of a component that has the `destructive-soft` background (for example a clickable red badge). Nothing existing changes.
